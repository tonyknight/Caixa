## Testing guide for human testers

From the repository root, with the development tools installed:

`python -m pytest -q && python -m black --check . && python -m mypy caixa tools/chattr/src && (cd web && pnpm exec tsc --noEmit && pnpm exec vitest run)`

On 2026-11-27 (Pacific), that suite was 2078 passed and 7 failed. The 7 are the known Chattr
web-convert failures. black reports only `tests/test_mail_sent_and_received.py`. mypy reports
8 known errors, none in the PDF prepare or author-knowledge modules. Web `tsc` is clean.
vitest was 249 passed and 37 skipped, because Playwright is not installed on the cloud machine.
The same pytest command can sit forever on `test_the_real_command_serves_a_page_and_stops_on_control_c`
unless `PYTHONUNBUFFERED=1` is set, because that test reads the server's link from a pipe.

On the maintainer's Mac, after `tools/install.sh`:

- Build the Apple Intelligence helper and run its check.
- `caixa benchmark` with the documents task, on the synthetic PDFs only.
- Import a real folder of PDFs and open a document in Safari's overlay.
- `caixa documents prepare <folder> --out <path> --box <box>`. Apple's copies are
  `<path>/Documents/PDF/`. The local model's copies are `<path> local`. The report is
  `<path>/report.txt`. The endpoint's own model is used even when Apple is selected for
  ordinary reading, and the key saved for that host is sent.
- Correct one document's author, or rename or merge two authors. `.caixa/author-knowledge.json`
  (mode 0600) records the accepted name. A one-document correction also records an instead
  with that document's kind. The box owner's name is never listed under rejected. Run prepare
  again with `--box`: a rejected name is not filed, and a matching instead is.

The checks below are the acceptance criteria. The automated tests already cover them; they are
listed so any one of them can be retried by hand.

### 20261124-01-synthetic-pdf-fixtures — Synthetic PDF fixtures

- Try: A builder writes the whole family into a folder from a fixed seed; two builds are byte-identical where the format allows (or differ only in documented ways)

- Try: A known-answers file describes each fixture: expected page classes, type, title, author, naming date and precision, key fields, filename conflicts, search words
- Try: Tests check the fixtures are what they claim (page counts, encryption, scanned pages without text, broken text layer garbled)

### 20261124-02-the-archival-naming-convention — The archival naming convention

- Try: Every example in the document is a test

## Backlog

- A standalone document-management application; an accounting system.
- Converting PDFs to HTML, or drawing them with a viewer of Caixa's own (no pdf.js): the browser's
  own viewer shows them.
- Changing, moving or deleting original files; removing a PDF's encryption.
- Sending document contents to any service on the internet: documents go only to a model on this
  computer, even when summaries or translation allow a remote service.
- Transaction-level financial extraction, linking cheques to bills, spending histories (draft phase
  7: backlog).
- Other formats (Word, spreadsheets, presentations, text): the domain and folder layout leave room
  for them; each will get its own collector.
- Requiring a model or OCR for an import to succeed.
- Merging two different files that hold the same document (they are flagged, not merged).
