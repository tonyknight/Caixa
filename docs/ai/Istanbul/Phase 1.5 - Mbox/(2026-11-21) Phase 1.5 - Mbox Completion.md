### 20261120-04-the-mbox-writer — The mbox writer

- **Outcome:** `caixa/mail/write.py` writes a Cleaned or Reduced mbox beside its source: `(YYYY-MM-DD) <name> [Cleaned|Reduced].mbox` (an earlier date and tag replaced, ` (2)` on a clash; a zip's folder; beside an Apple Mail `<name>.mbox`), after checking the folder can be written and has room. ## Testing guide for human testers

Run the verify command above first and confirm it passes, then walk through each ticket below by
hand.

**Setting up.** Use a new box (`caixa serve`, then make a box with an owner) so nothing real is at
stake. The synthetic noisy mailbox is the safest first source. Run from `tools/chattr/tests`:

```bash
python -c "from pathlib import Path; from fixtures.builders.noisy_mbox import build_noisy_mbox; print(build_noisy_mbox(Path('/tmp/noisy')).gmail)"
```

It prints the path of a Gmail-shaped mbox (56 mails) holding every case the tickets name. Then try a small
mbox of your own (a few hundred mails) and follow the checklist in `docs/Documentation/Collector.md`
(Mail → *Your first own mbox*). Never commit an mbox or anything drawn from one.

**The order to try things.** Import → Mail opens Clean mail: read the mbox (name the account), look
through the junk groups and Receipts, Keep a sender, write the Cleaned mbox. Open Sort mail on the
Cleaned copy: check Known, choose and ignore a few senders, confirm your addresses, import. Open a
person's page: the mail entries, Read the conversation (Escape, the cross, Open in its own window),
the conversation's cards, files and All headers. Open the box's index → Mail. With a model on this
computer (Ollama or LM Studio), turn on Settings → Summaries, Test summaries, then Summarize mail now
and read the summaries. Finally Write the reduced mbox and read it again. For ticket 14, open a box
made before this project (or a copy of one): a Pages redrawn job moves its files into `Attachments`
folders once.
