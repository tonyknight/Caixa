## Description

Select all rows of a Clean mail or Sort mail list at once, then deselect the few that should stay out.

## Acceptance criteria

- [ ] Every list in Clean mail and Sort mail has a Select all checkbox in its header; Ctrl/Cmd-A does the same
- [ ] Every row of the list is selected, also rows scrolled out of view; a click on a selected row deselects it
- [ ] The status bar says how many are selected, and the list's actions (Keep, Choose, Ignore, Don't import, Unignore) apply to them
- [ ] The checkbox shows all, none or some (indeterminate); the selection empties when the list changes
